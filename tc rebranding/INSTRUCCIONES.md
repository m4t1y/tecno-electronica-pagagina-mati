## 💻 3. CÓMO EJECUTAR O VISUALIZAR EL PROYECTO

1. **Abrir la web principal:**
   - Haz doble clic en el archivo `tc rebranding\index.html`.
   - Se abrirá en tu navegador predeterminado (Chrome, Edge, Firefox).

2. **Ver la presentación interactiva:**
   - Abre el archivo `tc rebranding\presentacion.html`.

3. **Ver el manual del timbre escolar:**
   - Abre `tc rebranding\manual-usuario-timbre.html`.

4. **Probar el Asistente Tecno-Bot:**
   - Dentro de `index.html`, haz clic en el icono del bot en la esquina inferior derecha para interactuar con él.

5. **Para proyectos de Arduino / Microcontroladores:**
   - El código para el inversor y temporizador está en `servicios\inversor 1seg\arduino_bc547_toggle\arduino_bc547_toggle.ino`.
   - Se puede abrir directamente con el **Arduino IDE**.
